🌲 Sistema de Gestão WoodWork

🔒 Projeto Privado

📖 Sobre o Projeto

Sistema de fluxo de produção (ERP) completo projetado sob medida para marcenarias. A plataforma contempla a gestão de pedidos, controle de estoque, acompanhamento de etapas de produção e automação de processos internos.

Nota: O código-fonte deste projeto é privado e não pode ser divulgado publicamente.

🚀 Minha Contribuição

  • Atuei como Desenvolvedor FullStack.
  • Desenvolvimento do sistema de autenticação e controle de acesso.
  • Implementação da integração com a API do WhatsApp.
  • Criação de dashboards e interfaces responsivas.
  • Estruturação das APIs internas e do banco de dados.

🛠️ Tecnologias

Laravel (PHP) MySQL API do WhatsApp Tailwind CSS
